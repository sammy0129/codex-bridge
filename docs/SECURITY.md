# 安全与恢复边界

## 授权模型

这是单人、多设备、每台主机独立部署的远程执行工具，不是多租户托管服务。配对设备拥有 Bridge 运行账户的操作能力。默认新任务请求 `danger-full-access` 和 `never`，这不代表获得操作系统管理员权限，也不会绕过 Codex 的管理要求。

主机要求不允许所选策略时返回 `POLICY_BLOCKED`，用户须明确选择受允许的策略。已有配置、登录文件和管理员要求不会被 Bridge 修改。

手机上的“任务权限”作用于 Codex 任务和新终端；文件编辑器是配对用户主动执行的文件操作，不是 Codex 只读沙箱。文件和 Git 接口限制在注册的项目目录，解析真实路径并拒绝越界链接；完整访问的终端不是项目目录安全沙箱。

历史图片接口是独立的只读例外：项目外文件必须被对应项目的可信任务历史用户消息以 `localImage` 明确引用，客户端只能提交消息定位信息，不能提交文件路径。接口拒绝链接/junction 路径、非普通文件、非支持的图片签名、超过 20 MiB 的文件，并检查打开前后与读取后的文件身份和真实路径。该保护不承诺对拥有主机文件修改权限的恶意本地进程提供完整隔离，也无法还原读取前已被原地改写的历史原图。现有文件浏览和编辑边界不变。

图片请求保持配对认证、证书固定和禁止重定向。外部 HTTPS 图片不附带 Bridge 凭证，也不通过 Bridge 代理。照片仅保留在有界内存缓存和相机的应用私有临时文件中；恢复元数据不包含凭证。切换主机清理图片缓存，离线永久图库不在本次功能范围内。

## 凭证与 TLS

- 配对码和设备凭证均为 32 字节随机值；配对码 5 分钟失效、原子消费。服务端只存哈希。
- 配对 HTTP 接口限流；后续接口要求 Bearer 凭证，WebSocket 握手也需认证。
- App 为每个主机创建独立 TLS 客户端。指纹模式不装载系统根证书，仅接受地址和 SHA-256 指纹匹配的证书；公网模式使用系统信任链。
- 认证 HTTP 不自动跟随重定向，凭证不放在 URL。
- 安卓凭证存于平台安全存储，备份关闭。会话缓存保存在应用私有目录，缓存不包含设备令牌。
- 主机数据目录在 Linux 使用用户私有权限，Windows 初始化时设置当前用户与 SYSTEM 的显式 ACL。该目录含私钥、记录和命令输出，应按敏感文件保护。
- Codex 登录令牌不会通过移动端 API 返回。不要把整个 `CODEX_HOME`、Bridge 数据目录或日志归档公开上传。

## 断线与副作用

手机连接不是执行进程的生命周期。Bridge 常驻 App Server 并维护待审批请求；手机断开后不调用停止或退订。只有用户显式停止、主机策略或执行端故障会结束任务。

请求按设备 ID 与 `requestId` 去重，摘要不同则拒绝重用。写操作在发往上游前写入日志。若进程崩溃或上游失联使结果不明确，返回 `OUTCOME_UNKNOWN`；客户端不会自动重发。网络世界中不存在靠重试即可保证的任意副作用“恰好一次”。

事件携带 `epoch` 和递增 `seq`，保留最近约 50,000 条。游标缺口、执行实例变化或不合法游标触发快照重建，而不是假装补齐全部旧流。终端只保留最近 128,000 个字符供重新附着，手机端滚屏缓冲有界。

数据库中的完成请求用于去重，不随事件窗口裁剪。长期使用应监控数据目录大小；首版没有自动销毁历史或执行清理任务的行为。

## 已知边界

- 一枚被盗的有效设备凭证相当于主机账户访问权。立即通过 CLI 撤销，并检查已执行操作。
- 服务只供自己的设备使用。不要把整个 App Server 端口直接暴露到公网，或把 Bridge 当成多人共享隔离服务。
- 外部客户端活动状态不是全局锁；从其他客户端继续会话前必须确认其停止。不能可靠确认时使用分叉。
- 文件版本校验可发现常见并发修改，但最终检查与替换之间仍有无法对所有非协作写入者消除的极短竞态。
- 初次配对需要可信的二维码传递渠道。不要扫描来源不明的配对 JSON，也不要分享配对码截图。
