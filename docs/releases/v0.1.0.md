# v0.1.0

发布日期：2026-09-20。

首个公开版本：个人远程编码工作台，非官方 Codex 客户端。包含 Flutter Android 客户端、HTTPS/WSS Bridge 和固定 Codex CLI 0.155.1 协议。

## Android 安装包

- 文件：`app-arm64-v8a-debug.apk`，仅提供 ARM64-v8a，不包含 ARMv7、x86_64 或通用 APK。
- 包名：`dev.codexbridge.codex_bridge`。
- 版本：`0.1.0`，分架构 versionCode：`2001`。
- 最低 Android 8.0（API 26），targetSdk 36。
- 大小：101862760 字节，约 97.14 MiB。
- 签名：Android Debug，供个人测试；不是正式发布签名。
- 正常 `lib/main.dart` 入口，不是集成测试 APK。

SHA-256：

```text
A75B4A8DEF9F0A26C790FB768B6CEE0948A0150B7E7C8F23C5B017C3DAC441A7  app-arm64-v8a-debug.apk
```

构建命令（`apps/android` 目录）：

```powershell
flutter build apk --debug --target-platform android-arm64 --split-per-abi
```
