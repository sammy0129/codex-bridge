# v0.1.1

发布日期：2026-09-20。

## 更新内容

- Android 手机抽屉与宽屏侧栏支持长按任务行，显示归档、恢复或删除菜单；长按不打开或选中任务。
- 永久删除前二次确认，调用 Codex 原生会话删除，不删除项目文件；不承诺擦除备份或 Bridge 已有审计、去重日志。
- 仅操作 Bridge 管理的空闲会话；离线、运行中、启动中、状态未知及待审批时显示中文禁用原因。旧 Bridge 保留归档功能，删除入口提示升级。
- Bridge 新增 thread/delete 与 threadDelete 能力，验证项目归属、状态和待审批请求，使用同一会话操作锁避免与启动并发。
- 删除后幂等清理列表、历史、图片缓存及草稿恢复状态；主机/项目切换、迟到响应和事件重放不会恢复已删除内容。未知结果不自动重试。

## 升级说明

客户端和 Bridge 均更新至本版本后才能使用删除功能。更新或构建磁盘文件不会替换正在运行的 Bridge；重启前需单独确认，并检查活动任务、终端、审批及未完成请求。保留现有数据目录、证书和配对记录；重连客户端以刷新能力列表，正常升级不需要重新配对。

配对凭据、证书/私钥、本地数据库、签名密钥及本机配置不包含在源码提交或 Release 附件中。
